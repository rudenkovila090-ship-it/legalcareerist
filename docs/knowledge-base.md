# Закрытая база знаний резидентов

**С 26.10.2026** в личном кабинете (`/cabinet/knowledge`) есть закрытая база знаний по карьере юриста: только для резидентов сообщества и администратора. Открытые статьи, PDF и видео (блог, соцсети) остаются бесплатными и открытыми: это воронка лидов. Закрытая база подробнее и глубже, она отдельная.

Содержимое перенесено из рабочего пространства сообщества (экспорт в Word, 26.10.2026): **40 страниц в 13 разделах**. Структура пересобрана заново, см. «Структура» ниже.

## Как это устроено
- **Хранение.** Обычные Markdown-файлы в папке `server/content/knowledge`: папка = раздел, файл = страница. Файлы читает только сервер; в код сайта, в `public/` и в карту сайта они не попадают. Папка лежит в репозитории (он закрытый) и приезжает на сервер с `deploy.sh`.
- **Доступ.** Сервер проверяет подписку при каждом запросе (дерево, страница, поиск): действующая или бессрочная подписка либо администратор. Подписка закончилась — доступ закрыт сразу (ответ 403 `members_only`). Клиент без подписки видит карточку «для резидентов» с кнопкой «Вступить» или «Продлить». Страницы не индексируются (`X-Robots-Tag: noindex`, кабинет закрыт от поисковиков).
- **Объём.** На сервере 38 ГБ диска, свободно около 34 ГБ (проверка 25.10.2026). Текст и PDF на годы не займут и гигабайта; тяжёлые файлы и видео в базу не кладём.

## Как выглядит и что умеет (по мотивам Notion)
- **Ширина (с 27.10.2026).** База занимает всю ширину рабочей области (до 96 rem), текст статьи — до 56 rem; панель и карточки уплотнены (карточки раздела в полтора раза меньше прежних, на широком экране три-четыре в ряд).
- **Панель слева:** дерево разделов с вложенностью, значки, счётчики страниц, «Избранное», кнопка «Свернуть все», у прочитанных страниц галочка. Строка «Поиск» открывает быстрый поиск.
- **Быстрый поиск ⌘K / Ctrl+K (или «/»):** окно по центру; ищет по названиям и тексту, слова подсвечиваются, стрелки выбирают, Enter открывает, Esc закрывает. Без запроса показывает «Недавние», «Избранное» и «Разделы». На телефоне открывается на весь экран (кнопка-лупа рядом с «Разделы»).
- **Страница раздела** (клик по разделу): обложка с названием и описанием, число страниц и «прочитано N из M», карточки страниц и подразделов с описанием, временем чтения и полоской прогресса.
- **Страница-статья:** путь-крошки, «В избранное» и «Ссылка» (копирует адрес), название, вступление (`summary`), чипы (раздел, время чтения, дата обновления, «Прочитано»), текст, кнопка «Отметить прочитанным», «Смотрите также» (`related`), «Назад»/«Дальше» по страницам того же раздела.
- **«На странице»** справа на широком экране: заголовки с подсветкой текущего при прокрутке; на узком экране это раскрывающееся «Содержание». Показывается, если заголовков второго уровня три и больше.
- **Выноски, раскрывающиеся блоки, ссылки между страницами:** синтаксис ниже.
- **Личные отметки** (избранное, прочитанное, недавние) хранятся в браузере читателя отдельно для каждого аккаунта (`localStorage`, ключи `ky_kb_fav:<логин>`, `ky_kb_read:<логин>`, `ky_kb_recent:<логин>`), на сервер не отправляются. Страница отмечается прочитанной сама, когда конец текста показался в окне; отметку можно снять. Очистка данных браузера или другой браузер — отметки начнутся заново.
- **На странице «Начало работы»** — карточки всех разделов (директива `::: sections`) и, если читатель уже что-то открывал, «Продолжить чтение».

## Как добавить материалы
Структура в репозитории:

```
server/content/knowledge/
  02-yuridicheskaya-kariera/
    _index.md                      ← название раздела, значок, описание (и вступление, если есть текст)
    01-poisk-raboty/               ← вложенный раздел
      _index.md
      01-rezyume.md                ← страница
```

- Порядок задают числа в начале имён (`01-`, `02-`…); в адресе они отбрасываются. Имена файлов — латиницей. Адрес страницы — путь без номеров и без `.md`, например `yuridicheskaya-kariera/poisk-raboty/rezyume`.
- В начале файла необязательный блок:

```
---
title: Резюме юриста
icon: briefcase
summary: Одно-два предложения: показываются под названием и на карточках.
related: yuridicheskaya-kariera/poisk-raboty/soprovoditelnoe-pismo, networking/kak-vystroit-set-kontaktov
draft: true
updated: 2026-10-26
---
```

  `title` — название (иначе возьмётся из имени файла; парные кавычки по краям снимаются); `icon` — значок (`flag, briefcase, scales, cap, compass, book, pen, spark, trend, coins, grid, leaf, chip, users, search, star, bulb, folder, doc`; у разделов по умолчанию папка, у страниц лист); `summary` — вступление над текстом и описание на карточках (без него на карточках берётся начало первого абзаца, а вступление над текстом не показывается); `related` — адреса страниц для «Смотрите также», через запятую (несуществующие и невидимые пропускаются); `draft: true` — черновик, видит только администратор; `updated` — дата обновления (иначе дата изменения файла).
- Текст — Markdown: заголовки `##`/`###`, списки (в том числе вложенные и нумерованные), **жирный**, *курсив*, `код`, [ссылки](https://…), цитаты `>`, таблицы с `|`, горизонтальная черта `---`. Сырой HTML не поддерживается. Блоки в духе Notion:

```
> [!TIP] Итог                      ← выноска (TIP — главное, NOTE — заметка, WARNING — важно)
> Текст выноски. Пустая строка
>
> между абзацами тоже с «>».

> [!QUOTE] Автор                   ← цитата-вставка

::: toggle Как найти нужное?       ← раскрывающийся блок: заголовок, текст, закрывающие «:::»
Нажмите Ctrl+K и введите слово.
:::

::: sections                       ← карточки всех разделов (на странице «Начало работы»)

[Резюме](kb:yuridicheskaya-kariera/poisk-raboty/rezyume)   ← ссылка на другую страницу базы
```

- Резидентам не видны: черновики, страницы без текста, разделы, где нет ни одной видимой страницы, и всё внутри черновика. Администратор видит всё, с пометкой «черновик» и счётчиком 0 у пустых разделов.
- Новые файлы появляются без перезапуска сервера (индекс обновляется раз в несколько секунд).
- **Проверка перед выкладкой:** `cd server && node scripts/checkKnowledge.js` — найдёт битые `related` и ссылки `kb:`, неизвестные значки, повторы названий, страницы без текста; напомнит про страницы без `summary` и пустые разделы.
- Опубликовать: убрать `draft: true`, закоммитить, `bash deploy.sh`.

## Где в коде
Сервер: `server/lib/knowledgeBase.js` (чтение файлов, дерево, видимость, поиск, проверка содержимого), маршруты `/api/account/kb`, `/api/account/kb/page`, `/api/account/kb/search` в `server/index.js` (`requireKb`), `server/scripts/checkKnowledge.js`. Сайт: `src/pages/cabinet/KnowledgeBase.tsx` (рабочая область), `src/components/KbMarkdown.tsx` (показ Markdown, выноски, блоки), `src/components/kb/` (значки, карточки, быстрый поиск, «На странице»), `src/lib/knowledge.ts` (запросы), `src/lib/kbState.ts` (избранное, прочитанное, недавние), `src/lib/kbHeadings.ts`; вход — пункт «База знаний» в меню кабинета и карточка на странице «Сообщество».

## Что не сделано
- Картинки, файлы и видео внутри страниц (сейчас только текст и ссылки). Картинки потребуют отдельной выдачи с проверкой подписки: вход в кабинет идёт заголовком, а не cookie, поэтому обычный `<img>` без токена не подойдёт.
- Вложенные PDF, запись вебинара Чередовой, базы «Российские юристы», «Юридические фирмы», «Юридические направления» (см. «Не перенесено»).
- Отметки читателя пока только в браузере (без синхронизации между устройствами).
- Резервная копия: ежедневная копия данных в Telegram не включает `server/content`, но эти файлы лежат в репозитории.
- Страницу создания и правки материалов в самом кабинете (сейчас файлы и деплой).
