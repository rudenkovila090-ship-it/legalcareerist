## Публикация

Из зафиксированного коммита во временной папке: `npm ci --no-audit --no-fund`,
`npm run build`, затем `node scripts/publish-community-page.mjs --commit SHA`.
Итог успешной установки: `JAZZ_PARTNERS_PUBLISHED`.

Рабочий Git checkout не переключается. Публикуется статическая сборка с
резервной копией и проверкой; API, бот, закрытая база знаний, платежи,
доступы и серверные настройки не изменяются. Из облачной среды установка
на рабочий сервер не выполнялась.
