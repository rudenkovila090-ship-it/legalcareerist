# Воронки выдачи материалов в Telegram-боте

Это замена «ключевых слов», «приветствия» и «диплинков» из конструкторов чат-ботов (BotHelp и подобных), но внутри вашего бота и без оплаты посреднику.

```
Instagram: автоответ или ссылка                      Telegram-бот
  «гайд» → текст + диплинк  ───────────────────►  приветствие по имени / запуск воронки
                                                       │
                       вопросы кнопками ◄──────────────┤
                       проверка подписки на канал      │
                       выдача материала (ссылка, файл) │
                       напоминание, опрос, дожим       ▼
                                                 карточка менеджеру, метки, статистика
```

## Что в конфигурации (`config/funnels.json`)

У каждой воронки:

| Поле | Что делает |
|---|---|
| `id` | короткое имя (латиница, цифры, до 12 символов); входит в диплинк |
| `keywords` | кодовые слова. `гайд*` ловит «гайд», «гайды», «Гайд!». Работает в коротких сообщениях (до 6 слов) и не перехватывает ответы на вопросы анкеты |
| `button` | подпись кнопки в приветствии (пусто — не показывать) |
| `intro` | вступительное сообщение; `{first_name}` подставит имя клиента |
| `quiz` | вопросы кнопками перед выдачей (2–6 вариантов); ответы сохраняются метками |
| `gate` | `true`: перед выдачей проверять подписку на канал (нужен `SUBSCRIBE_CHANNEL`) |
| `gate_text`, `not_subscribed`, `reminder`, `reminder_minutes` | тексты проверки подписки и через сколько минут напомнить неподписавшемуся (один раз) |
| `survey` | опрос «почему не хотите подписываться» (кнопки), вопрос и спасибо |
| `deliver` | выдача: `text`, `buttons` (ссылки `url` или переходы в другую воронку `funnel`), `document_url` (файл по ссылке, до 20 МБ) |
| `followup` | сообщение через N минут после выдачи (один раз), например предложить консультацию |
| `then_segment` | после выдачи запустить анкету: `candidate`, `community`, `booking`, `event` и т.д. из `flows.json` |

Что подставляется автоматически: ссылка «Подписаться» берётся из `SUBSCRIBE_CHANNEL` (или `CHANNEL_URL`).

**Воронка с незаполненной ссылкой (`<ссылка на …>`) отключается сама**, остальные работают. Какие отключены, видно в `--check`, в `/stats` и в логе. Кнопки на отключённые воронки пропадают из меню и приветствия.

## Что соответствует шаблонам из BotHelp

| Шаблон BotHelp | Здесь |
|---|---|
| «Выдача лид-магнита с проверкой подписки» (приветствие → «Я подписан» → проверка → файл; не подписан → напоминание через 10 минут → опрос → прощание; метка «новый подписчик») | воронки `guide` и `longlist`: `gate`, `reminder_minutes`, `survey`; метки `subscriber`, `got:<воронка>`, `opros:…` |
| «Чат-бот с выдачей лид-магнита» (имя → 2 вопроса кнопками → ссылка на статью) | `quiz` + `deliver` в воронке `guide` |
| «Чат-бот для приёма заявок» (выбор дня кнопками → телефон с проверкой формата → «менеджер свяжется») | анкета `booking` в `flows.json` (типы вопросов `choice` и `phone`), запускается воронкой `consult` |
| «Ключевое слово» | `keywords` воронки |
| «Приветствие» (при входе по поиску или ссылке; в Telegram срабатывает на каждый `/start`) | сообщение `welcome_new` (первый раз) и `welcome_back` (повторно) в `funnels.json` |
| «Диплинк» (ссылка на конкретный шаг бота) | `?start=<id воронки>__<метка>` и `?start=seg_<анкета>__<метка>`; список печатает `python -m bridge.tgbot --links` |
| Мини-лендинг | не делали: для этого нужна страница на вашем сайте |

Чего нет (нужно, скажите): повтор вопроса анкеты, если клиент не ответил; свободный текстовый ответ в опросе (сейчас только кнопки); рассылки по меткам; оплата в боте (кнопка «Купить» ведёт на вашу страницу).

## Как связать с Instagram

Автоответ Instagram (Business Suite → Inbox → Автоматизации → «Свои ключевые слова», до 5 слов) отправляет коротко и со ссылкой на нужный шаг бота:

```
Здравствуйте! Гайд уже ждёт вас в нашем боте — нажмите и получите:
https://t.me/LegalcareeristBot?start=guide__ig_dm
```

Одна автоматизация на каждый материал, ссылка своя. Так клиент остаётся в Instagram до первого шага, а материал, проверку подписки, анкету и заявку ведёт бот.

## Проверка перед запуском

1. `python -m bridge.tgbot --check`: ✅ у бота, чата менеджеров и канала (бот администратор); список воронок.
2. Напишите боту `/start`, затем кодовое слово, пройдите воронку со второго аккаунта: и подписанным, и неподписанным.
3. Дождитесь напоминания (по умолчанию 10 минут), проверьте, что материал открывается.
4. В группе менеджеров: `/stats`, `/contacts`.
