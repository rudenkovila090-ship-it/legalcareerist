# Страница сообщества: обновление дизайна v14

20 ноября 2026 года. Визуальное обновление `/community` по рекомендациям
UI UX Designer: ясная иерархия, эффективное использование пространства,
минимализм и сдержанный характер профессионального клуба.

## Что показал анализ

| Проблема | Изменение | Зачем |
| --- | --- | --- |
| Текст таблицы на телефоне — 10,4 px | Основной текст таблицы — 13 px на телефоне, 14 px на компьютере | Читать возможности без увеличения страницы |
| Равные строки сетки раздували блок миссии до 828 px | Строки подстраиваются под содержимое; блок — 612 px при ширине 1440 px | Сохранить композицию «миссия слева, ценность и цель справа» и убрать лишнюю высоту |
| Первый экран конкурировал с рамкой вокруг описания | Более крупный заголовок, открытая композиция, единая ось с кнопкой | Быстрее понять назначение сообщества |
| На карте заранее резервировалась пустая правая колонка | Карта центрирована; университеты появляются по выбору города | Не показывать пустой информационный блок |
| Тарифы терялись среди одинаковых мелких подписей | Крупная цена, обозначение оплаты за весь период, единый размер карточек | Проще сравнивать сроки и понимать сумму оплаты |
| Тарифы занимали 1088 px по высоте на телефоне | Компактная компоновка цены и подписи | Сократить прокрутку при выборе периода |
| Вертикальная схема платформ занимала 574 px на компьютере | На широком экране схема горизонтальная; на телефоне вертикальная | Показать связь двух платформ и четырех возможностей компактнее |
| Разные тени, градиенты и фоновые плашки | Общие поверхности, тонкие границы, одинаковые радиусы и отступы | Спокойный, последовательный визуальный язык |
| У окна оплаты не было полноценного управления фокусом | Нативный dialog, цикл Tab/Shift+Tab, Escape и возврат фокуса | Доступное оформление подписки с клавиатуры |

## Визуальная система

- Основной акцент: Blue Hour `#2A4D85`; фон: `#FFFFFF`.
- Основной текст: `#283953`; вторичный: `#53657E`.
- Темные поверхности: `#1D2E49`; светлая поверхность: `#F4F7FB`.
- Локальный Inter; фирменный логотип и PT Sans в общей шапке сохранены.
- Общая ширина, согласованные поля; отступы и размеры кратны 4/8 px.
- Тонкие геометрические линии на первом экране, плоская модульная карта,
  схема цифровых платформ. Декоративная графика скрыта от скринридеров.
- Стили изолированы в `src/pages/community/community.css`.

## Содержание и поведение

Сохранены порядок разделов, все 11 возможностей, карта трех городов,
циклическая лента десяти амбассадоров, четыре имеющиеся фотографии,
три оригинальных изображения достижений, отзывы, форма амбассадора и FAQ.
Согласованные заготовки «В разработке» и желтые ответы FAQ сохранены.

Тарифы: 1 месяц — 690 ₽, 6 месяцев — 3180 ₽, 3 месяца — 1770 ₽.
Порядок 1–6–3 и первоначальный выбор шести месяцев сохранены. Условия
промокода, состав заявок, серверные обработчики и согласия не изменены.
Выбор периода и оплата теперь отдельные нативные кнопки.

## Проверка

- `npm run build`: TypeScript и сборка Vite.
- `npm run lint`: без ошибок; остаются прежние предупреждения в других файлах.
- Проверка в Chromium при ширинах 320, 360, 390, 768, 1024, 1440 и 1920 px:
  отсутствие горизонтального переполнения, тарифы, карта, FAQ, формы и клавиатура.
- `scripts/tests/community-dialog-browser.py`: все три периода, цикл фокуса,
  Escape, возврат на кнопку оплаты, восстановление прокрутки.
- `scripts/tests/community-promo-browser.py`: 12 сценариев тарифов и промокода
  на странице сообщества и странице материала. Ответы API подменены тестовыми.
- `scripts/tests/publish-community-page.py`: публикация реальной сборки в
  изолированный каталог, проверки файлов, повторный запуск и откат при ошибках.

Проверки браузера не подтверждают реальное банковское списание или доставку
сообщений в Telegram. Для этой задачи они не выполнялись.

## Публикация

Существующий `scripts/publish-community-page.mjs` дополнительно проверяет
наличие новых стилей и записывает версию дизайна в отчет публикации.
Запускать с собранным `dist` из проверенного коммита. Публикация создает
резервную копию статики и проверяет результат через публичный адрес сайта.
При ошибке восстанавливает прежние файлы; ранее опубликованные хешированные
ресурсы остаются доступны. Серверные данные, `.env`, API и бот не заменяются.
