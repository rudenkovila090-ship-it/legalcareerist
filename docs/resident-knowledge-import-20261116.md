## Поиск и фильтры

Штатный фильтр «Раздел» находит страницы в своей папке и родительском
разделе. Поиск по названию работает в верхней панели, включая `b2b`
в нижнем регистре и «7 способов». Полнотекстовый поиск открывается кнопкой
«Поиск по тексту · Ctrl K», сочетанием Ctrl+K / Cmd+K либо `/`.
Проверены слова из основного текста: `Follow-up`, `ценовая толерантность`,
`автоматизировать`, `комьюнити`, `солиситора`.

## Установка

После получения зафиксированного коммита через `git archive` выполните
`node scripts/install-resident-knowledge.mjs`. Сборка сайта и установка
зависимостей для этого изменения не требуются.

Скрипт читает `pm2 jlist`, находит работающий `legalcareerist-api`, учитывает
его `KB_DIR` и файлы окружения. Он проверяет здоровье API и ответ 401 без
входа на дерево, страницу и поиск. Затем добавляет только отсутствующие
пять файлов в существующие разделы. Другое содержимое файла, совпадающий
адрес, измененный исходник или ссылка вместо файла останавливают установку.

Папки и прежние статьи сохраняются. Создается приватная копия всей прежней
Markdown-базы и отчет в `/root/legalcareerist-bot-backups/resident-knowledge-20261116-*`.
Каждый новый файл устанавливается атомарно без перезаписи существующего.
При ошибке удаляются только файлы, добавленные этим запуском, если их
никто не изменил параллельно. Повтор установки проверяет результат без
записи и дублей. PM2 используется только для чтения списка процессов:
перезапуск API или бота не выполняется. Индекс базы обновляется за 5 секунд.

После проверки всех пяти страниц для резидента, разделов, текста и поиска,
а также повторной проверки здоровья и закрытого доступа скрипт выводит
`RESIDENT_KNOWLEDGE_PUBLISHED`.

## Проверено

- Валидатор базы: 45 страниц, все новые связи корректны. Единственное
  прежнее замечание — пустой раздел «Сервис», к новым статьям не относится.
- Установка на отдельном стенде: успех, повтор без записи, пользовательский
  `KB_DIR`, сохранение прежних статей и платежей, отказ при конфликте,
  символьной ссылке, дубле адреса и измененном исходнике; отказ при открытом
  API; откат при ошибке проверки после установки, сохранение параллельной
  правки владельца.
- Реальные обработчики API на изолированной копии: оплаченный, бессрочный
  бесплатный резидент и резидент с разрешением владельца получают все пять
  статей, администратор также; без входа — 401, без доступа и с истекшим
  сроком — 403. Исходящие запросы к внешним сервисам отключены.
- Личный кабинет в браузере: пять статей, сочетание раздела и поиска по
  названию, полнотекстовый поиск, чтение и заголовки на 320/390/768/1440 px.

Снимки и журналы: `/workspace/artifacts/resident-knowledge-20261116`.
Проверки выполняются локально; установку на рабочий сервер подтверждает
вывод команды, которую запускает владелец.
