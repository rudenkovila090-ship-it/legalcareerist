# Прямые ссылки на вакансии

У всех шести вакансий есть отдельная страница `/vacancies/<slug>` с полным
описанием и контактами. Теперь общий компонент детальной карточки показывает
кнопку «Скопировать ссылку» под датой публикации.

Из встроенной карточки во вкладке «Соискателям → Вакансии» копируется адрес
конкретной вакансии, а не адрес вкладки. Рядом доступна ссылка «Открыть отдельно».
Скопированный адрес всегда использует `https://legalcareerist.ru`, без параметров
и фрагментов текущей страницы. Состояние копирования сбрасывается при выборе
другой вакансии. Если Clipboard API недоступен или запрещен, показывается
выделенное поле со ссылкой для ручного копирования.

Проверки: сборка, линтер, шесть адресов, копирование из встроенной карточки,
переход по прямой ссылке и перезагрузка, смена вакансии, запрет Clipboard API,
отсутствие переполнения на 320/390/1440 px; существующие проверки доски и публикации.
