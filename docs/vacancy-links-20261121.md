# Прямые ссылки на вакансии

У всех шести вакансий есть отдельная страница `/vacancies/<slug>` с полным
описанием и контактами. По уточнению владельца карточки во вкладке соискателя
теперь сразу открывают эти страницы: адресная строка меняется при нажатии
на саму карточку. Ссылку можно скопировать обычным способом из браузера.

Встроенная подмена списка содержимым вакансии удалена. Кнопки «Скопировать
ссылку» и «Открыть отдельно», а также поле ручного копирования удалены.
Обычные ссылки поддерживают открытие в новой вкладке. Перезагрузка и открытие
адреса в другом окне показывают ту же вакансию без предварительного посещения списка.

Вкладка и фильтры списка сохраняются в query-параметрах страницы соискателя.
При возвращении кнопкой браузера «Назад» или ссылкой «Все вакансии» открывается
исходный список с выбранными фильтрами. Прямые ссылки на вакансии фильтры не содержат.

Проверки: сборка, линтер, переход по всем шести карточкам, изменение адресной
строки, перезагрузка, новая вкладка, возврат с фильтрами, отсутствие удаленных
кнопок и переполнения на 320/390/1440 px; проверки доски и публикации.
