# Переезд с бота BotHelp (@legalcareerist_bot) на нашего бота @LegalcareeristBot

Наш самописный бот **@LegalcareeristBot** уже работает на сервере (токен в `server/.env`, вебхука нет: бот получает сообщения опросом). **Токен менять не нужно.** Старый бот @legalcareerist_bot остаётся в BotHelp, людей переносим в нашего бота. Все сценарии, оплаты Prodamus и кабинет админа остаются прежними.

**Не запускать:**
- `scripts/setup-bot.sh`: он меняет токен бота на сервере. Для этого переезда токен не меняется.
- `server/scripts/announceMove.js` в нынешнем виде: он пишет от имени бота из `server/.env`, то есть от нашего нового бота, которому люди ещё не писали, а Telegram не даёт боту писать первым. Сообщение «мы переехали» отправляет BotHelp-бот (шаг 2).

## Порядок

0. **Свежая выгрузка из BotHelp** (Подписчики → Экспорт, в файле должна быть колонка «дни»). Пока BotHelp не работает, подойдёт и файл от 30.09.2026.
1. **Загрузить людей без смены токена.** С админского аккаунта отправьте **нашему боту @LegalcareeristBot** файл выгрузки с подписью `/import`. Бот покажет, что найдёт (сколько людей, подписок с оставшимися днями, бессрочных, «на проверку»), и после кнопки «Загрузить» заведёт карточки, метки, согласия на рассылку и подписки. Повторная загрузка безопасна: подписки с настоящими оплатами не трогаются, прежние импортные обновляются по новой выгрузке. То же умеет скрипт: `node server/scripts/importBotHelp.js файл.csv --dry` и без `--dry`. Загруженным людям наш бот пока не может написать первым: Telegram разрешает это, только когда человек сам нажал Start. Поэтому нужен шаг 2.
2. **Сообщить людям о переезде рассылкой из BotHelp.** Сообщение «мы переехали» со ссылкой на @LegalcareeristBot и просьбой нажать Start отправляет **BotHelp-бот** (рассылка в самом BotHelp): он пишет тем, кто с ним уже общался. Кто нажал Start у нашего бота, получает его уведомления и доступ.
3. **Обновить сайт и сервер:** `bash deploy.sh` (ссылки на бота на сайте и в письмах станут вести на @LegalcareeristBot).
4. **Проверить с вашего аккаунта:** нажмите Start у @LegalcareeristBot и посмотрите в админ-кабинете «Состояние системы» и «🔎 Проверить чат» (бот должен быть админом чата сообщества с правами приглашать и блокировать).
5. **Адрес уведомлений Prodamus.** Продления по автоплатежам засчитываются, когда уведомление приходит на `https://legalcareerist.ru/api/prodamus/webhook`. Если у старых подписок в настройках Prodamus стоит адрес уведомлений BotHelp, до нас они не дойдут. **Порядок такой:** сначала отключите в BotHelp автоисключение из чата сообщества (иначе BotHelp, перестав получать оплаты, решит, что подписка закончилась, и исключит платящих), и только потом меняйте адрес уведомлений в Prodamus (настройки платёжной страницы → уведомления) на наш.

## Как подписки считаются из выгрузки

| Что в файле | Что получает человек |
|---|---|
| дней больше нуля и есть метка «резидент_сообщества», «оплатил_подписку_…», «подписка_350» или «подписка_500» | подписка на столько дней, сколько осталось |
| те же метки «подписка_350» / «подписка_500» | разовая подписка на 30 дней (350 / 500 ₽), без автопродления |
| дней больше 3650 (в BotHelp так помечены основатели) | бессрочная подписка (до 2045 года) |
| дни есть, но меток оплаты нет | не заводится сам: бот показывает список «на проверку» и кнопку «Загрузить и завести подпиской „на проверку“» |
| метка резидента, дней нет или меньше нуля | подписка закончилась, доступ не выдаётся |
| id не из 5–11 цифр (в выгрузке 30 таких) | пропускаются: это не Telegram, боту они недоступны |
