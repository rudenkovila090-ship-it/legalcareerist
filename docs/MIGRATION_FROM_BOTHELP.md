# Переезд с BotHelp на свой бот

Цель: отключить BotHelp и ничего не потерять. Порядок важен: **BotHelp отключаем последним**, когда всё уже проверено в нашем боте.

## 1. Тот же это бот или другой

От этого зависит всё остальное.

- **Тот же бот** (BotHelp подключён по токену @LegalcareeristBot): люди остаются доступны, им не нужно ничего нажимать заново. Но у токена один «слушатель»: пока BotHelp подключён, наш бот запустить нельзя. Переключение делается за минуту: отвязать канал в BotHelp, запустить наш бот.
- **Другой бот**: Telegram разрешает писать только тем, кто сам запускал именно этот бот. Старым контактам придётся нажать «Старт» заново. Их нужно позвать из старого бота сообщением (пока BotHelp ещё работает).

Как узнать: на сервере запустите `python -m bridge.tgbot --check`. Если у бота включён webhook, в красной строке будет написан сайт. Если там `bothelp...`, значит бот держит BotHelp, и он тот же. Если webhook не используется, а BotHelp-бот живёт под другим именем, то он другой.

## 2. Перенос людей, меток и подписок

Выгрузка контактов из BotHelp → файл на сервере. Сначала пробный запуск, он ничего не пишет:

```bash
python -m bridge.bothelp_import export-21102026.csv
python -m bridge.bothelp_import export-21102026.csv --apply     # записать
```

Что переносится:
- **люди из Telegram** с именем и настоящими датами первого и последнего контакта;
- **все метки** как есть (`оплатил_лонглист`, `резидент_сообщества`, `подписка_350` и т.д.), плюс `import:bothelp`;
- **согласие на рассылку**: `mailing:yes` только у тех, у кого стоит «согласен». Если нет метки, или стоят обе метки сразу, рассылка запрещена;
- **промокод** меткой `promo:КОД`;
- **подписки**: «дни» в выгрузке считаем от даты выгрузки (она берётся из названия файла) и записываем дату окончания. Больше 10 лет считаем «бессрочно» и показываем в списке на проверку.

Безопасно запускать повторно (свежая выгрузка перед самым переездом): контакты и метки только добавляются, живые данные не затираются.

Что **не** переносится: люди из Instagram (им отсюда писать нельзя), email и телефоны (в нашей базе для них нет поля; файл выгрузки сохраните).

## 3. Что делает BotHelp, а у нас ещё нет

Это то, что по меткам видно, что у вас продаётся и работает. Без этого отключаться рано.

| Что | Статус | Что нужно |
|---|---|---|
| Приветствие, меню, гайды, кнопки, анкеты, заявки менеджеру | есть | сверить тексты со сценариями BotHelp |
| Консультация, запись | есть | сверить |
| Оплата лонглиста (`оплатил_лонглист`, 4 чел.) | **нет** | чем принимаете оплату и как выдаёте материал |
| Подписка на сообщество (`подписка_350`, `оплатил_подписку_1/2`) | **нет**: в базе хранится дата окончания, но оплаты и продления нет | платёжный сервис, цены, как выглядит «подписка 1» и «подписка 2» |
| Доступ в закрытый чат (`резидент_сообщества`, `бета_доступ`) | частично: умеем убирать из чата при отписке | выдача ссылки после оплаты, напоминание о продлении, удаление после окончания |
| Промокоды (`KQ21`) | **нет** | как работают: скидка, бесплатные дни |
| Оплата мероприятия (`оплатил_мероприятие`) | **нет** | нужно ли |
| Рассылки по меткам | **нет** | нужны ли; только по `mailing:yes` |

## 4. Согласие на рассылку

В BotHelp согласие хранится меткой, а доказательство (текст, дата нажатия) только у них. После отключения доказать нечем. Поэтому: сохраните файл выгрузки и тексты сообщений, где спрашивали согласие, а в нашем боте лучше один раз спросить заново кнопкой «Разрешаю рассылку» перед первой рассылкой.

## 5. Порядок переезда

1. Определить, тот же это бот или другой (п. 1).
2. Скачать сценарии BotHelp (скриншоты всех шагов: меню, оплаты, подписка, доступ в сообщество, промокоды).
3. Дописать недостающее из п. 3.
4. Запустить наш бот **на тестовом боте** с копией базы, пройти всё руками, включая оплату.
5. Свежая выгрузка из BotHelp → `bothelp_import --apply`.
6. Переключение: отвязать Telegram в BotHelp → запустить наш бот → проверить `/start`, меню, оплату.
7. Неделя наблюдения: BotHelp не удаляем, а только отключаем канал.
8. Последняя выгрузка и отмена платной подписки BotHelp.
