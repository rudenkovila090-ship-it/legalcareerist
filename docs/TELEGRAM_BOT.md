# Telegram-бот @LegalcareeristBot: приём заявок

Основной путь воронки: **Instagram даёт трафик, бот принимает заявки в Telegram**. Не нужны ни приложение Meta, ни App Review, ни сторонние платформы, ни домен: бот сам опрашивает Telegram (long polling).

## Как это работает

1. Клиент попадает в бота по ссылке с меткой: `https://t.me/LegalcareeristBot?start=ig_story_oct17`.
2. Бот показывает меню (кнопками): юридическая помощь, подбор юриста в команду, поиск работы, сообщество и мероприятия.
3. Если задан `PRIVACY_URL`, бот запрашивает согласие на обработку персональных данных (кнопки «Да, согласен(а)» / «Нет»).
4. 2–3 коротких вопроса по выбранному сегменту.
5. В чат менеджеров приходит карточка: сегмент, **источник** (из ссылки), имя и ссылка на клиента, ответы.
6. Менеджер **отвечает (reply) на карточку**, и ответ уходит клиенту от имени бота (текст, фото, файлы, голосовые). Пока менеджер ведёт диалог, бот молчит, а новые сообщения клиента приходят менеджеру.

Слова «менеджер» (позвать человека), «стоп» (отказ от автосообщений) и «меню» работают на любом шаге. Тексты и вопросы правятся в `config/flows.json` без программиста.

## Запуск

Нужно: Python 3.12+ или Docker, токен бота, группа менеджеров. Сервер должен выходить в интернет к `api.telegram.org`: входящий трафик, домен и сертификат не нужны.

### 1. Токен и группа
- Токен: BotFather → ваш бот → API Token → `TELEGRAM_BOT_TOKEN`.
- Создайте группу менеджеров и добавьте в неё @LegalcareeristBot.
- Узнайте ID группы (он нужен для запуска):

```bash
export TELEGRAM_BOT_TOKEN=...             # токен из BotFather
python -m bridge.tgbot --find-chat        # затем за 60 секунд напишите в группе /chatid
```

Скрипт напечатает ID группы (начинается с `-100…`). Он ничего не подтверждает в Telegram, поэтому сообщения не потеряются.
Если группа не находится, откройте BotFather → Bot Settings → Group Privacy и проверьте, что бот видит команды (по умолчанию видит).

### 2. Настройка
```bash
cp .env.example .env     # заполните TELEGRAM_BOT_TOKEN, TELEGRAM_MANAGER_CHAT_ID, PRIVACY_URL
set -a; . ./.env; set +a
pip install -r requirements.txt
python -m bridge.tgbot --check --test-message
```

`--check` проверяет токен, отсутствие чужого webhook, доступ бота к группе и показывает предупреждения. `--test-message` присылает менеджерам тестовое сообщение. Запускайте только после зелёных ✅.

### 3. Запуск
```bash
python -m bridge.tgbot
```

В продакшене запускайте как сервис с автоперезапуском (Docker, systemd). Базу заявок (`DB_PATH`) держите на постоянном диске.

```bash
docker build -t legalcareerist-bot .
docker run -d --restart=always -v bot-data:/data --env-file .env legalcareerist-bot
```

Сборку Docker-образа я в разработке не проверял: в среде не было Docker-демона. Первый запуск проверьте командой `docker logs`.

## Если @LegalcareeristBot уже где-то работает
У одного токена может быть только один «слушатель». Бот откажется стартовать, если у токена включён webhook (в `--check` будет ❌), и покажет ошибку `Conflict`, если уже работает другой опрос. Что делать:
- остановить старый процесс (лучше всего: тогда весь функционал будет в этом боте), либо
- завести у BotFather **нового** бота и использовать его токен для приёма заявок, либо
- запустить с `TG_FORCE_POLLING=1`: webhook удалится, а старый процесс перестанет получать сообщения. Делайте это, только если вы уверены.

## Instagram как источник трафика

- **Метки в ссылках.** Для каждого места своя ссылка: `?start=ig_bio` (шапка профиля), `ig_story_oct17` (сторис), `ig_post_vakansii` (пост), `qr_jazz2` (QR на мероприятии). Допустимы латиница, цифры, `_` и `-`, до 64 символов. Источник виден в карточке, в `/leads` и в выгрузке.
- **Шапка профиля.** Поставьте `t.me/LegalcareeristBot?start=ig_bio` в поле ссылки и призыв в описании («Оставьте заявку в боте — ссылка выше»).
- **Сторисы.** Стикер «Ссылка» с меткой конкретной сторис. В посте и рилсах: призыв и закреплённый комментарий с ссылкой.
- **Мероприятия.** QR-код с меткой события на афише и экране: например, для «Джазового вечера для юристов».
- **Сообщения в директ** отвечайте вручную из Instagram (Business Suite → Inbox) и зовите клиента в бота ссылкой с меткой. Официальный автоответ в Instagram возможен только через собственное приложение Meta: код для него лежит в репозитории и описан в [INSTAGRAM_SETUP.md](INSTAGRAM_SETUP.md).

## Команды

В чате менеджеров:
- `/leads`: последние 10 заявок;
- `/export`: все заявки файлом CSV (открывается в Excel и Google Таблицах; значения, похожие на формулы, экранируются);
- `/help`: подсказка.

В любом чате: `/chatid` показывает ID чата. Остальные команды работают только в чате менеджеров, посторонние группы бот игнорирует.

## Персональные данные

Бот собирает контакты и сведения о запросе. Это персональные данные:
- задайте `PRIVACY_URL` со ссылкой на политику обработки данных. Тогда бот запросит согласие до сбора контактов (без этой переменной шаг пропускается, а `--check` предупредит);
- первый вопрос для клиентов юрфирмы намеренно общий («какая тема»), чтобы подробности дел не оставались в переписке бота. Не добавляйте вопросов о деталях дела;
- заявки хранятся в SQLite-файле на вашем сервере. Организуйте доступ к серверу и резервные копии, определите срок хранения;
- токен бота и содержимое `.env` не публикуйте. Если токен попал в чужие руки: BotFather → ваш бот → API Token → Revoke current token.

Текст и юридическую форму согласия согласуйте с вашим юристом.

## Что проверено

Автотесты (97) и сквозной запуск настоящего процесса против локального имитатора Telegram: меню и кнопки, весь диалог, источник из ссылки, карточка менеджеру, ответ менеджера клиенту, перевод диалога на менеджера, сохранение позиции опроса, отсутствие токена в логах.

**Не проверено вживую:** обращения к настоящему Telegram и Docker-образ. Первый запуск начните с `--check --test-message`.
