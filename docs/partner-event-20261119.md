`peresborka-yuridicheskogo-produkta-19-noyabrya-2026`.
Два одинаковых анонса в сообщении владельца объединены в одну запись.

- Формат: очно, Москва, Mercure Arbat Moscow, Смоленская площадь, 6.

- Стоимость не указана владельцем: `price: null`, тарифы и оплата на нашем
  сайте не создаются. Блок программы и аудитория заполнены по анонсу.

Афиша показана в сообщении, но не передана как доступный файл. Проверены
`/workspace/attachments`, `/workspace/shared`, артефакты и файлы проекта;
нового оригинала нет. Попытка открыть ссылку регистрации через штатный
сетевой клиент отклонена прокси: CONNECT 403. `go.urbiz.pro` отсутствует
в разрешенных доменах среды. Заменяющее изображение не создавалось,
поле `cover` остается незаполненным до получения исходного JPG/PNG.

Сборка и линтер прошли. В браузере на 320, 390, 768 и 1440 px проверены
единственная карточка, поиск, фильтры «Москва» и «Очно», переход на страницу,
московское время, адрес, программа, две внешние ссылки регистрации,
отсутствие собственной формы оплаты и горизонтального переполнения.

подменялся, переход к внешней регистрации не выполнялся.

На рабочий сервер изменения не устанавливались. При публикации нужен
обновленный статический сайт; для учета просмотров и переходов API также
нужна эта запись в `server/data/event-catalog.json`. Сервер читает каталог
на каждом запросе, перезапуск бота или API для этого не требуется.

## Команда публикации

`scripts/publish-community-page.mjs` поддерживает параметры
`--event-slug peresborka-yuridicheskogo-produkta-19-noyabrya-2026`
и `--server-checkout /var/www/legalcareerist` вместе с обычным `--commit`.
Запуск — от root после сборки зафиксированного коммита во временном каталоге.
Серверный checkout не переключается, сервисы не перезапускаются.

Скрипт добавляет только новую запись в существующий серверный каталог.
Остальные мероприятия, их цены и дополнительные поля сохраняются.
Существующая запись этого slug с другими данными останавливает операцию
до запросов и записи. Отсутствующий или поврежденный каталог также
не заменяется каталогом из облачной среды.

Перед обновлением создается приватная копия `event-catalog.before.json`
в той же резервной папке, что и файлы сайта. Права и владелец каталога
сохраняются. При провале проверки возвращаются прежние сайт и каталог;
чужое параллельное изменение каталога не перезаписывается при откате.
После установки проверяются публичная страница мероприятия, sitemap,
JS/CSS и прежние проверки страницы сообщества. Успешное завершение
подтверждается строкой `PARTNER_EVENT_PUBLISHED`. Повтор исправной
публикации не создает дублей и ничего не перезаписывает.

Интеграционные проверки прошли на реально собранной dist с подмененными
HTTP и nginx: сохранение платного мероприятия с серверной ценой и полями,
повтор без записи, восстановление отсутствующей записи при уже новом
сайте, откат обоих источников при HTTP 404 страницы, неверном sitemap
или ошибке расчета подписки, отказ при конфликтующей записи до HTTP
и записи. На рабочем сайте эта проверка ничего не меняла.
