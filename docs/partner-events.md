# Партнёрские мероприятия на афише

Мероприятие партнёра добавляется записью в `src/data/events.ts` (одна запись — одна карточка в афише `/events`, страница `/events/<slug>`, афиша в кабинете «Мероприятия» и адрес в карте сайта). Пример — `kutafin-legal-cup-xvi` (XVI кейс-чемпионат Kutafin Legal Cup, 28.11.2026).

## Поля партнёрского мероприятия

| Поле | Зачем |
|---|---|
| `partner` | «Партнер: …» на странице и метка «Партнер» на карточке |
| `externalRegistration: true` | регистрация только у организатора: на странице нет тарифов, нашей формы билета и заявки «Стать партнёром мероприятия», вместо них кнопка на сайт организатора и условия участия; на карточке подпись «регистрация у организатора» |
| `registrationLink` | форма регистрации организатора (клики считаются, как у остальных внешних регистраций) |
| `cover` | афиша организатора: файл в `public/events/<имя>.jpg`, путь `/events/<имя>.jpg`. На странице стоит справа от заголовка, в афише и в кабинете показывается целиком по её пропорциям. Не импортировать картинку в `events.ts` (файл читает скрипт сборки каталога) |
| `keyDates` | «Важные даты»: `{ when, what }`; первая дата повторяется в карточке регистрации |
| `directions` | «Направления и компании-кураторы»: `{ title, curator }` |
| `documents` | «Документы и ссылки»: `{ kind: 'file' \| 'link', title, url, note }`; файлы лежат в `public/documents/<имя>.pdf` (права 644), ссылка `mailto:` тоже допустима |
| `organizer` | блок «Организатор» (название, описание, сайт) |
| `description` | абзацы разделяются пустой строкой (`\n\n`) |
| `type: 'championship'` | тип «Кейс-чемпионат» (есть в фильтре афиши) |

Цена `price: 0` показывается как «Бесплатно», мероприятие попадает в подборки «Бесплатные мероприятия» и «Для студентов» (если `audienceLevel` содержит `student`). В `tariffs` нужен хотя бы один тариф (страница его читает, хотя при `externalRegistration` не показывает).

После правки `npm run build` пересобирает каталог мероприятий для сервера и карту сайта.
