# Компактная доска вакансий

Вкладка «Соискателям → Вакансии» начинает список с фильтров. Повторный видимый заголовок «Вакансии / Доска вакансий» удалён; семантический заголовок оставлен для скринридеров. На отдельной странице /kadry/vacancies — один заголовок «Вакансии».

На компьютере высота фильтров около 142 px вместо прежних 206 px: уменьшены высота полей, интервалы и внутренние отступы. Сохранены все девять фильтров. На телефоне размер шрифта полей 16 px, чтобы ввод не вызывал приближение iOS. Варианты «Все» больше не дублируют значения disabled-placeholder, поэтому фильтр можно сбросить. Города берутся из действующих вакансий; добавлена отсутствовавшая категория IT для уже опубликованной вакансии.

Общий компонент VacancyCardContent выравнивает поля карточек по строкам: двухстрочный заголовок, компания, город, зарплата, сфера и действие. Длинные заголовки/компании доступны полностью через title и внутри вакансии. Карточка показывает основной тег направления, основной тег отрасли и число остальных тегов; все теги доступны внутри вакансии. При отсутствии зарплаты стоит честная подпись «Зарплата не указана».

Карточки уменьшены примерно до 198 px, добавлена видимая кнопка-подсказка «Посмотреть вакансию». Вся карточка остаётся одним доступным элементом: button для открытия внутри вкладки и Link для отдельной страницы. Вложенных кнопок/ссылок нет.

Просмотры из списка и запрос /api/vacancies/views убраны. VacancyDetailBody не менялся: открытие вакансии учитывает просмотр и показывает статистику внутри. Количество найденных вакансий осталось над списком.

Проверка: scripts/tests/vacancy-board-browser.py — все девять фильтров, сброс, выбор Елабуги/IT, сохранение фильтра после просмотра, выравнивание каждой строки, компактная высота, отсутствие просмотров в списке, статистика внутри и две страницы на 320/390/768/1024/1440 px. Тест использует подставные API-ответы и не отправляет заявки.

На мобильных экранах вкладки соискателя теперь выравниваются по началу прокручиваемой строки: прежний justify-end скрывал первые пункты за левой границей и мешал открыть вакансии. На компьютере сохранено выравнивание справа.
