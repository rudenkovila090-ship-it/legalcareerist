# Фотоотчёты с мероприятий

Страница отчёта: `/events/<адрес мероприятия>/photos` (компонент `src/pages/events/EventPhotos.tsx`). Снимки разной высоты стоят «кирпичной кладкой» (схема Masonry, `docs/layouts.md`), по нажатию открываются на весь экран (`src/components/Lightbox.tsx`: стрелки на клавиатуре, Esc, кнопки). На странице самого мероприятия при наличии отчёта появляется кнопка «Фотоотчёт» (у вечера «Джазовый вечер для юристов 2» в авторском оформлении кнопки нет, ссылку на отчёт дайте напрямую). Пока отчётов нет, список пуст, ни кнопки, ни страницы в карте сайта нет, по прямому адресу показывается «Фотоотчёта пока нет».

## Как добавить отчёт

1. Подготовьте снимки: по длинной стороне 1600 px, JPG, до 300 КБ каждый (с телефона они весят по 3–8 МБ, сайт станет тяжёлым). Имена файлов латиницей: `01.jpg`, `02.jpg`…
2. Положите их в `public/photoreports/<адрес мероприятия>/` (адрес берётся из `src/data/events.ts`, поле `slug`).
3. Добавьте запись в `src/data/photoReports.ts`:

```ts
{
  eventSlug: 'адрес-мероприятия',
  description: 'Короткий текст про вечер (по желанию)',
  photographer: 'Имя фотографа (по желанию)',
  photos: [
    { file: '01.jpg', alt: 'Что на снимке', width: 1600, height: 1067 },
    { file: '02.jpg', alt: 'Спикер на сцене', caption: 'Подпись под фото (по желанию)', width: 1067, height: 1600 },
  ],
}
```

`width` и `height` (размеры файла в пикселях) необязательны, но с ними страница не «прыгает» во время загрузки. `alt` нужен обязательно: это описание снимка для людей, которые не видят картинку.

4. Адрес `/events/<адрес>/photos` попадает в карту сайта при следующей сборке (`bash deploy.sh`) сам.

На снимках могут быть люди: публикуйте только те фотографии, на которые есть согласие на публикацию (`/legal/consent-publication`).
