# Обложки полезных материалов

Подготовлены необязательное поле `MaterialItem.cover`, общий компонент MaterialCover, обложки над содержимым карточек и рядом с приобретением на странице продукта. Изображение вписывается целиком, без обрезки надписей. Карточки ограничивают описание тремя строками и выравнивают цену снизу. Оплата и выдача файлов не менялись.

9 ноября получен ZIP с восемью PNG 1199×1312. Исходники сохранены побайтно в public/materials/covers, имена содержат хеш для обновления браузерного кэша. Каталог материалов связывает изображения с соответствующими продуктами. Обложки загружаются лениво в каталоге и показываются целиком. Для карьерного планирования CSS ограничивает видимую область соответствующим нижним макетом исходного коллажа; файл не перерисован и не изменён.

Для лонглиста «Юридические мероприятия» в разработке отдельной обложки нет. Не использовать для него студенческую обложку: это другой продукт.

Пакет установки включает восемь изображений, каталог и компоненты обложек. До запуска команды на Timeweb изменения не применены к действующему сайту. Проверка scripts/tests/material-covers-browser.py охватывает восемь карточек и восемь страниц на 320/390/768/1440 px; запросы оплаты во время тестирования блокируются. Основной каталог /marketplace и раздел /events/materials используют единый компонент MaterialCover.
