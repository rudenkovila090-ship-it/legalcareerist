# Восстановление ошибочно исключённых резидентов, 10 ноября 2026

Скриншот журнала Telegram подтверждает блокировки ботом Анастасии Шемонаевой, Дианы Плиевой и Кристины Бреховой. Ранний вывод `absentReviewsClosed:3` не доказывал отсутствие блокировок; прежний вывод о полной исправности был недостаточным. Ошибка политики состояла в разрешении исключения по просроченной карточке при неполной сверке исключений владельца и оплат. Дополнительно обработчик прекращал бессрочную льготу при любом удалении из чата, не различая действие администратора и добровольный выход.

## Изменения

- Постоянный файл `data/community-removals-paused.json` запрещает исключения. Установщик сначала останавливает основной процесс, устанавливает эту защиту и только затем применяет остальные изменения. При ошибке остаётся прежний работающий код с запретом исключений. Снятие паузы в этом пакете не предусмотрено. Оплаты, повтор принятых вебхуков, уведомления и вступления работают независимо от паузы. Старая подписанная операция offboard во время паузы отклоняется до банковских действий.
- Бессрочная льгота Анастасии, ID 376201355, восстанавливается без платежей, с номинальной меткой 350 ₽. Удаление ботом, администратором или событие разблокировки больше не считается добровольным выходом. Для окончания льготы требуется статус left с актором, совпадающим с самим резидентом.
- Диана, ID 1955667679 (@mulanka_7), получает отдельное разрешение владельца оставаться в сообществе. Кристина @civillaw_civile и Мария @vmashik получают допуск по прямому подтверждению владельца об оплате. Это отдельное право `ownerAccess`, не выдуманная запись о поступлении денег и не новый договор списаний. Такие записи исключены из подбора платёжных договоров. Интерфейс кабинета обозначает этот допуск отдельно.
- Telegram ID Кристины и Марии определяется по существующей карточке, точному нику бота или сохранённой заявке; неоднозначность не разрешается догадкой. При отсутствии ID создаётся допуск по точному нику, привязываемый только при настоящем сообщении/заявке Telegram. Этот случай не называется успешным снятием блокировки.
- С известных ID снимается блокировка с only_if_banned. Уже поданные заявки одобряются. Если заявки ещё нет, возвращение требует перехода самого участника по приглашению; бот не может принудительно добавить пользователя Telegram. Установщик показывает приглашение и раздельно сообщает joined/awaitingJoin.
- Имеющиеся подписанные события Prodamus по целевым участницам повторно применяются только при отсутствии заказа в финансовой истории. Повторы не дублируют деньги. Отсутствие вебхука не маскируется: разрешение владельца позволяет вступить, а проверка оплаты остаётся отдельной.
- Уведомление администратору записывается в одной транзакции с платежом. Доставка подтверждается отдельно, с повтором через минуту после отказа Telegram; идемпотентность платежа не теряет сообщение. Принятые события повторяются независимо от включения автоисключений.
- Приглашение также требует подтверждённой разблокировки, иначе остаётся в очереди. Известный ботом плательщик с сайта опознаётся по точному нику и текущему ответу Telegram, получает приглашение без необходимости сначала подать заявку.

## Проверки и применение

135 модульных проверок; 16 HTTP-сценариев именно этого восстановления; ранее в этом изменении также прошли 26 проверок синхронизации и 30 основных HTTP-проверок. Четыре сценария установщика: успех/повтор, неизвестный модуль, отказ перезапуска, отказ здоровья. Проверяются сохранность финансовой истории и сохранение запрета исключений при откате. Все внешние сервисы в тестах подменены, банковских списаний нет.

Пакет `updates/community-access-rescue` содержит точные контексты и контрольные суммы. `scripts/install-community-access-rescue.mjs` меняет только активный основной API. Отчёт сохраняется в `/root/legalcareerist-bot-backups/access-rescue-20261110-*`. Маркер `ACCESS_RESCUE_APPLIED` подтверждает установку прав и ответов разблокировки, но не означает, что ожидающие вступления уже находятся в чате, и не подменяет отсутствующий платёж.

Здесь нет SSH-доступа к Timeweb. До запуска опубликованного установщика нельзя утверждать, что живые блокировки сняты.
