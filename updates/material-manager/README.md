# Загрузка платных гайдов через сайт

Обновление поддерживает версию `947d6b4` и обнаруженное сочетание файлов этой версии с исходными файлами `b14a93b`. Для каждого файла принимаются только точные контрольные суммы этих двух проверенных сборок; неизвестные изменения останавливают установку. Разворачивается весь согласованный набор файлов, затем их содержимое проверяется до и после перезапуска API. Настройки, оплаты и данные клиентов не заменяются. Откат сохраняет точные исходные файлы сервера, включая обнаруженный старый `server/index.js`.

После установки владелец входит в `/cabinet/manage-materials`. В меню появляется «Материалы сайта». Для каждого гайда можно выбрать PDF из любой папки компьютера и нажать «Загрузить PDF». Создавать отдельную папку или переносить файлы через PowerShell не требуется.

Доступ к списку файлов, загрузке и восстановлению проверяется сервером по сессии владельца. Резидентам раздел и API недоступны. Сам PDF остаётся в закрытой папке сервера; покупатели получают существующие личные ссылки после оплаты. Финансовые настройки и расписание бота не меняются.

Первая загрузка трёх отсутствующих гайдов проверяет точное содержимое последних файлов, присланных владельцем 2 ноября. Это исключает случайную загрузку предыдущих редакций с теми же названиями. После первой загрузки владелец может заменять PDF новыми редакциями. Перед заменой и после загрузки сохраняются версии, которые можно восстановить кнопкой в кабинете.

Файлы передаются небольшими частями, поэтому для этих PDF не требуется менять лимиты nginx. Незавершённая загрузка не заменяет действующий материал. При завершении проверяются размер, SHA-256 и формат PDF. Временные части не входят в резервную копию данных бота; действующие PDF и версии входят. Копии версий на сервере не заменяют внешнюю резервную копию при утрате самого сервера.

Установка запускается через `scripts/install-material-manager.mjs`, который сам выбирает нужный пакет без длинного присваивания переменной в терминале. Сначала сборка и тесты, затем короткая остановка API, приватная копия проекта, применение файлов и проверка нового закрытого API и публичного сайта. Автоматическое исключение участников остаётся выключенным. При ошибке — откат кода с сохранением актуальных оплат и данных.

Проверки: 15 сценариев API управления материалами и резервных копий, 24 интеграционных сценария текущего API, 14 прежних модульных сценариев. Браузером проверена загрузка именно трёх актуальных PDF в отдельную тестовую копию, отказ для другого файла, размеры частей, мобильная вёрстка и отсутствие управления у резидента. Реальные платежи и сообщения покупателям не использовались.
