# Исправления сайта и подписок

Пакет подготовлен для проверки и установки. Наличие ветки само по себе не меняет Timeweb.

- Публичные формы показывают «Заявка получена» после сохранения серверной записи. Ошибка сохраняет заполненную форму; повтор использует тот же номер. Сбой Telegram не теряет заявку. Приложенные файлы сохраняются отдельно и повторно отправляются при сбое.
- Обязательные согласия проверяются сервером до записи заявки. Входящие записи доступны только администратору кабинета и включены в удаление персональных данных.
- Сайт и бот используют один конец оплаченного периода, без четырёх дополнительных дней. Бессрочные подписки сохраняются. Карточки без даты требуют проверки; автоматически людей по ним не исключаем.
- Проверка исключения из Telegram каждые 30 секунд включается существующим `AUTO_EXCLUDE=1`. Администраторы чата, действующие дубли подписки и ошибки проверки Telegram защищены от исключения. Изменение доступа не отменяет автосписание Prodamus. После оплаты снова доступна ссылка на вступление; автоматически добавить человека в Telegram нельзя.
- Подтверждения продления хранят очередь отдельно по Telegram и почте. Неудачное напоминание не отмечается доставленным. Чужой платёж не считается доказательством неудачного списания конкретного клиента. Запоздавший старый платёж сохраняет текущий оплаченный срок.
- Даты в сообщениях продления содержат секунды и московский часовой пояс. Если Prodamus не прислал следующий срок, сохраняется прежний расчёт по тарифу; поле `nextPaymentSource` отличает его от даты провайдера. Сам расчёт не доказывает точное время будущего списания.
- Расписание напоминаний сохранено: за два календарных дня и за один день, после 10:00 Москвы. Вариант за 12 часов и в момент списания ожидает решения владельца.
- Черновики кабинетов соискателя и работодателя остаются скрытыми прототипами. Рабочий кабинет резидента `/cabinet` сохраняется.
- Обновлены Vite/source-map-js, multer и nodemailer. `npm audit` для обоих пакетов: 0 известных уязвимостей на момент подготовки.

## Проверка перед установкой

`scripts/check-site-readonly.mjs` проверяет состояние процесса, параметры фоновых задач, целостность JSON, три платных PDF, доступность сайта/Telegram и авторизацию SMTP без отправки письма. Вывод не содержит токенов, паролей и данных клиентов.

## Копии и оставшаяся работа

GitHub хранит код. Ключи, клиенты, оплаты, сессии и загруженные платные PDF туда не входят. Копия из бота неполная. `scripts/backup-site-private.sh` создаёт дополнительный полный локальный архив с правами 600; он не заменяет внешнюю копию и ещё не включён в расписание.

Старое файловое хранилище финансовых записей в этой версии не менялось. Предложение: атомарная замена файла, отдельная предыдущая проверенная версия, отказ от записи при повреждении. Миграция нужна отдельным шагом с проверкой восстановления.

Защита входящих Telegram/Prodamus уведомлений, ранее отмеченная аудитом, остаётся отдельным открытым вопросом. Этот пакет не делает неподписанные уведомления безопасными. Причины трёх реальных неоплат и актуальная настройка исключения требуют проверки на Timeweb и в Prodamus.

`node server/tests/http-reliability.mjs` — отдельный временный HTTP-сервер; все пользователи вымышленные, внешние отправки заменены заглушками.

`npm run lint` и `npm run build` пройдены. Проверено 14 модульных сценариев, 18 интеграционных HTTP-сценариев и 7 браузерных сценариев, включая отказ localStorage. Все финансовые события вымышленные.
