# Режимы каналов. Скопируйте этот файл в channels.txt и поправьте под себя:
#     cp channels.example.txt channels.txt
#
# Формат строки:   режим: название канала
# Название нужно писать точно так, как его показывает команда  python -m digest channels  (или @ник канала).
# Строки с # игнорируются. Каналы, которых нет в файле, работают в режиме all.
#
# Режимы:
#   all        брать и мероприятия, и вакансии (по умолчанию)
#   events     только мероприятия: для новостных каналов и блогов, где вакансий не бывает
#   vacancies  только вакансии: для бирж вакансий
#   news       только новости о людях рынка (переходы, назначения, повышения, понижения, награды); юридический
#              контекст не проверяется
#   law        только законодательство и судебная практика по трудовым спорам (новые законы, законопроекты,
#              разъяснения ведомств, решения судов о труде)
#   agency     вакансии показываются отдельным списком «через агентства»: каналы рекрутеров и конкурентов
#   off        канал совсем не читать

# Пример: новости и блоги, вакансий там не ищем (проверьте названия по своему списку)
events: PROбанкротство
events: Право.ru
events: Слово защите
events: KALOY.RU

# Пример: каналы о законах и судебной практике (подставьте названия из своего списка)
# law: Верховный суд, новости
# law: Налоговый вестник

# Пример: каналы рекрутеров, их вакансии идут отдельным списком
agency: To Hunt a Lawyer
agency: Вакансии для юристов Lue Sky Legal Recruitment
agency: Legal Talents | Legal Jobs & CVs
agency: Magic Staff
