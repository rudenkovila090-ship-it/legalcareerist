# Кабинет и блог: пакет 9 ноября 2026

Пакет содержит единый профиль и навигацию кабинета, личную записную книжку, подтверждение контактной почты, компактные мероприятия, фильтры базы знаний и обновление блога/подкаста. Дата второго сезона, выпуск 0: 1 ноября 2026. Дата выпуска 1 не указана. Все 16 выпусков первого сезона сохранены.

Установка: `node scripts/install-resident-ui.mjs updates/resident-ui` под root на действующем сервере. Снаружи берутся обе блокировки `/run/lock/legalcareerist-site.lock` и `/run/lock/legalcareerist-subscriptions.lock`.

Установщик находит живые runtime API и демо через PM2 и исходники текущей публичной сборки через Nginx и deployment.json. Он собирает новую версию отдельно от Git-каталога. Серверные изменения применяются небольшими контекстными патчами; незнакомые исходники останавливают установку до записи. Новая библиотека accountEmail.js проверяется по SHA256. Остальные библиотеки API контролируются до и после установки. Платёжные данные, .env и настройки автоматизации не заменяются.

После сборки сначала обновляются API, проверяются здоровье и прежние параметры подписок, затем переключается Nginx. Проверяется публичный HTML и хеш входного JS. При сбое выполняется восстановление кода и Nginx. Резервные файлы и build.log остаются в закрытой папке; её путь печатается в конце.

Проверки:
- Сборка проекта из опубликованного дерева, TypeScript.
- HTTP-проверки кабинета и 28 сценариев изоляции демо.
- Playwright: кабинет, общий профиль карьеры/вакансий, записная книжка, блог и подкаст на 320–1440 px.
- `node scripts/tests/resident-ui-install.mjs`: успех, повторный запуск, несовместимые исходники, ошибка сборки, перезапуска API и публичной проверки. Nginx/PM2/npm в этой проверке подставные, рабочие данные не используются.

Исправление совместимости: установщик не изменяет residentDemo.js. Запрет смены почты в общем демо выполняется в новой библиотеке accountEmail.js при RESIDENT_DEMO_MODE=1. Существующий, в том числе минифицированный, sandbox сохраняется побайтно и контролируется вместе с прочими неизменяемыми библиотеками.

Совместимость прежних сборок: src/lib/leadFormCompatibility.ts предоставляет новым страницам вспомогательные функции и тип requestId, используя существующий src/lib/leads.ts для отправки заявок. Сам транспорт и серверный контракт /api/notify не заменяются. `node scripts/tests/resident-ui-legacy-build.mjs` сначала воспроизводит ошибку предыдущего пакета на b14a93b, затем проверяет успешную сборку исправленного пакета и побайтную неизменность старого leads.ts. Ошибки TypeScript при неудачной установке теперь выводятся непосредственно в консоль.

Обложки: восемь оригинальных PNG в public/materials/covers с проверкой SHA256. Используются в каталоге, разделе полезных материалов и на страницах продуктов. Текст на макетах не обрезается; для карьерного планирования показан соответствующий макет из коллажа через CSS. Цены и оплата сохранены. Публичные файлы обложек входят в тот же пакет.

Доска вакансий: фильтры компактнее, повторный заголовок вкладки удалён, карточки имеют единые строки и действие «Посмотреть вакансию». Просмотры остаются только внутри вакансии. Счётчик результатов сохранён. Девять фильтров и возврат к списку проверяются scripts/tests/vacancy-board-browser.py.
