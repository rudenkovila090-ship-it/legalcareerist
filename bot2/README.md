# Второй бот (бывший бот из BotHelp)

Отдельный код со своими сценариями, своими данными и своим процессом. Основной бот и сайт (`server/`) он не трогает.
Работает на том же сервере. Платежи подписок приходят из Prodamus на его собственный адрес (`BOT2_PUBLIC_URL`).

Готово:
- `lib/tariffs.js` — 8 подписок из кабинета Prodamus (ID, цена, срок). Какие из них продаются новым покупателям, задаёт поле `sale`.
- `lib/prodamus.js` — подписанные ссылки на оплату (`do=link&subscription=ID`) и проверка подписи уведомлений.
- `scripts/make-link.mjs` — проверка ссылок без бота: `node bot2/scripts/make-link.mjs` (список) и
  `node bot2/scripts/make-link.mjs 3m --tg 123456789 --short` (ссылка на страницу оплаты).
- Проверки: `node --test bot2/test/tariffs.test.mjs`.

Дальше: приём сообщений, загрузка выгрузки BotHelp файлом через Telegram, приём уведомлений об оплатах, сценарии.
