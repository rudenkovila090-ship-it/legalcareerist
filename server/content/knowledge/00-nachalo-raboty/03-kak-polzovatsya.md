Если не получилось найти нужное — загляните в вопросы и ответы ниже.

::: toggle Как пользоваться базой знаний?
База знаний разделена по направлениям. Сначала выберите нужный блок, а затем откройте карточку, видео, PDF или ссылку с материалом.
:::

::: toggle Кто имеет доступ к базе знаний?
Доступ к базе знаний есть только у резидентов сообщества.
:::

::: toggle Можно ли самому добавлять или менять материалы?
Если у вас есть желание добавить материал, предложить правку или обновить раздел, напишите в поддержку **@legalcareerist_support**.
:::

::: toggle Что делать, если я не нашёл нужный материал?
Проверьте соседние разделы или воспользуйтесь навигацией по базе.

Если материал всё равно не нашёлся, напишите в поддержку **@legalcareerist_support**.
:::

::: toggle Что делать, если ссылка или файл не открываются?
Сообщите об этом в поддержку **@legalcareerist_support**, и мы проверим материал.
:::

::: toggle Можно ли использовать материалы вне сообщества?
Материалы базы предназначены для внутреннего использования резидентами сообщества.

Если есть вопросы по использованию, напишите в поддержку **@legalcareerist_support**.
:::
