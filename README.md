# Карьерный Юрист

Фронтенд-прототип сайта «Карьерный Юрист» на React + TypeScript + Tailwind CSS,
реализующий архитектуру связности из ТЗ: единую таксономию (специализация /
отрасль / аудитория), сквозной компонент `<RelatedContent>`, единый личный
кабинет, единый LeadCapture и разделы Кадры / Сообщество / Мероприятия.

## Что реализовано

- **Модель данных** (`src/types.ts`) — сущности User, CandidateProfile,
  EmployerProfile, Vacancy, Article, EventItem, MaterialItem, CommunityClub,
  Lead и др. по разделу 4 ТЗ.
- **Единая таксономия** — специализация (адвокатура/консалтинг/инхаус/
  госслужба), отрасль права, аудитория контента — используется как фильтр
  на вакансиях, мероприятиях и Базе знаний.
- **`<RelatedContent>`** (`src/components/RelatedContentBlock.tsx` +
  `src/lib/related.ts`) — переиспользуемый блок «Связанное» на детальных
  страницах вакансии, статьи, мероприятия, материала и клуба; подбирает
  объекты других типов по пересечению тегов. Клик шлёт аналитическое
  событие `related_content_click`.
- **`<ProcessSteps>`** — переиспользуется в «Работодателям» и на странице
  мероприятия.
- **LeadCapture** (`src/lib/leads.ts`) — единая точка приёма всех форм
  сайта; в этом прототипе пишет в localStorage (эмуляция общей таблицы
  лидов), в проде — интеграция с CRM/Telegram-ботом.
- **Личный кабинет** (`/account`) — демонстрирует единый аккаунт: отклики,
  регистрации на мероприятия, покупки материалов и членство в клубе видны
  в одном месте для одного пользователя.
- **Зарплатный навигатор** (`/kadry/salary`) — новый раздел из п.6.7 ТЗ.
- **Скидка участникам клуба сообщества на мероприятиях** (п.6.6) —
  логика в `src/pages/events/EventDetail.tsx`.

## Ограничения прототипа

Это фронтенд с mock-данными (`src/data/*.ts`), без бэкенда, оплаты,
Telegram-бота и CRM — они описаны в ТЗ как отдельные интеграции (раздел 7–8)
и требуют серверной части. Модель данных и компонентная архитектура
спроектированы так, чтобы эти интеграции подключались поверх без
переделки фронтенда.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
```
