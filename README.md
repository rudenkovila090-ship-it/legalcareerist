# Карьерный юрист — личный ассистент в Telegram

Бот-помощник основателя. Живёт в Telegram, а вся «память» — в вашей Google Таблице
**«КЮ: ежедневный журнал и сводка»**. Бота можно перезапускать и переносить: ничего не потеряется.

## Что он делает

| Когда | Что |
|---|---|
| Вы пишете отчёт свободным текстом | Claude разбирает его, бот показывает, что понял, и после кнопки «Записать» вносит в **Действия**, **Обращения**, **Продажи** |
| ☀️ Каждое утро | Кому написать сегодня и по какому вопросу, что просрочено, задачи дня, какие показатели отстают |
| 🌙 Каждый вечер | Что уже записано за день, что не закрыто, напоминание прислать отчёт |
| 🗓 Понедельник | План недели по дням: из плана на год + текущего темпа + воронки людей |
| 📈 Воскресенье и конец месяца | Разбор: что достигнуто, что нет, на что сделать упор |
| 🎯 1-го числа | Предложение целей месяца из плана на год (применяются только после вашего «Применить») |

Примеры отчётов, которые бот понимает:

- «Написал 15 работодателям, 3 ответили, 1 созвон. Написал кандидат из инсты, ищет работу. Продал резидентство за 3500, оплачено полностью»
- «Полина из Стрижа согласна, созвон в пятницу»
- «Анна доплатила 1500 за резидентство»
- «Поправь вчера: касаний было 20, а не 15»
- «Сделал задачи 12 и 14, задачу 15 перенеси на среду»

## Как это устроено

```
Вы ──Telegram──▶ бот ──▶ Claude (разбор текста, планы, разбор итогов)
                  │
                  └──▶ Google Таблица  (Действия · Обращения · Продажи · Планы · Сводка
                                        + «План года» и «Задачи», которые бот создаёт сам)
```

Правила, о которых бот договаривается с таблицей:

- Даты пишутся **числами** (формат `дд.мм.гггг`): локаль таблицы en_US, текст «16.10.2026» она бы не поняла.
- **Продажи, колонки «Статус оплаты» и «Долг»** — формулы. Бот в них не пишет.
- **«Обращения → Статус шага»**: бот ставит `просрочен` (его считает «Сводка»), `сделано` или оставляет пустым. Ваши собственные пометки не трогает.
- Списки «Источник», «Кто обратился», «Этап», «Направление» бот **читает из листа «Планы»**: добавили этап — бот его знает.
- Всё, что меняет ваши жёлтые цели в «Планах», идёт только через подтверждение кнопкой.

## Установка

Нужно ~30–40 минут один раз.

### 1. Telegram

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите **токен**.
2. Откройте **@userinfobot** → он пришлёт ваш числовой **ID**. Бот будет отвечать только этому ID.

### 2. Доступ к таблице (сервис-аккаунт Google)

1. [console.cloud.google.com](https://console.cloud.google.com) → создайте проект.
2. «APIs & Services» → «Library» → включите **Google Sheets API**.
3. «IAM & Admin» → «Service Accounts» → создайте аккаунт → вкладка «Keys» → «Add key» → **JSON**. Скачается файл.
4. Откройте таблицу → «Настройки доступа» → добавьте **email сервис-аккаунта** (из файла, поле `client_email`) как **Редактора**.
5. `SPREADSHEET_ID` — это кусок ссылки между `/d/` и `/edit`.

### 3. Ключ Claude

[console.anthropic.com](https://console.anthropic.com) → API keys → создать. Сразу поставьте лимит расходов в настройках.

### 4. Проверка на своём компьютере

```bash
pip install -r requirements.txt
cp .env.example .env        # заполните значения; для Google локально удобнее GOOGLE_SERVICE_ACCOUNT_FILE=путь/к/ключу.json
python -m bot.selfcheck --llm
```

`selfcheck` проверит Telegram, доступ к таблице, структуру листов и один раз вызовет Claude на тестовом отчёте
(ничего при этом не записывая). Все строки должны быть с ✅. Без `--llm` Claude не вызывается.

### 5. Запуск 24/7

Боту нужен **постоянно работающий процесс** (не «засыпающий» сервис): иначе не придут утренние сообщения.
Входящие порты не нужны — бот сам опрашивает Telegram. Подойдёт любой хостинг, который запускает
Docker-контейнер или фоновый процесс (worker): Railway, Render (Background Worker), Fly.io или обычный VPS.

```bash
docker build -t kyu-assistant .
docker run -d --restart unless-stopped --env-file .env kyu-assistant
```

На хостинге задайте переменные из `.env.example`. В `GOOGLE_SERVICE_ACCOUNT_JSON` вставьте **содержимое** JSON-ключа целиком.

### 6. Первый запуск

Бот напишет «🤖 Ассистент запущен», создаст в таблице вкладки **«План года»** и **«Задачи»** и покажет расписание.
Дальше: `/year` — загрузить план на год, `/plan` — первый план недели.

## Команды

`/today` утренний список сейчас · `/tasks` задачи недели · `/plan` пересоставить план недели · `/stats` сводка и светофор ·
`/review` разбор недели · `/month` разбор месяца · `/year` загрузить план на год · `/targets` цели месяца · `/myid` ваш ID

**План на год** можно прислать текстом (в несколько сообщений, затем «Готово») или файлом PDF / TXT / MD / CSV.
Бот разложит его на цели по периодам (год, квартал, месяц) и сохранит в «План года»; лист можно править руками.
Word и Excel пока не читаются: сохраните как PDF или вставьте текст.

## Настройки

Все в `.env.example`. Главные: `TIMEZONE`, время сообщений (`MORNING_TIME`, `EVENING_TIME`, `WEEK_PLAN_TIME`, `WEEK_REVIEW_TIME`),
`FOLLOWUP_DAYS` (через сколько дней напомнить о человеке, у которого не задан срок шага), `CLAUDE_MODEL`.

## Стоимость

Грубая оценка при 1–2 отчётах в день: **около 5–8 $ в месяц** на модели по умолчанию `claude-opus-5-5`
(4 $ / 20 $ за млн токенов на входе/выходе). Реальные цифры смотрите в консоли Anthropic. Дешевле вдвое:
`CLAUDE_MODEL=claude-sonnet-5-5`. Хостинг — отдельно, обычно несколько долларов.

## Чего пока нет

- Пересылки в реестры («План-работы | Кадры», «Финансы | Сообщество» и др.) — бот пишет только в журнал; пересылка остаётся за чатом с Claude.
- Голосовых сообщений (нужен отдельный сервис распознавания речи).
- Word / Excel как источник плана года.
- Работы с несколькими пользователями: бот одноличный.

## Безопасность и данные

- Бот отвечает только владельцу (`OWNER_TELEGRAM_ID`); `/myid` отвечает всем, но раскрывает лишь ID спросившего.
- Ключи хранятся только в переменных окружения. `.env` и `*.json` в `.gitignore`; не коммитьте ключи.
- Сервис-аккаунт видит только те таблицы, которые вы ему открыли.
- Текст ваших отчётов (имена, ники, суть запросов) уходит в Claude API и проходит через Telegram. Если вносите персональные данные
  кандидатов, убедитесь, что это соответствует вашим согласиям и политике обработки данных.
- Запись в таблицу — только после вашего «Записать»; версии таблицы можно откатить через «Историю изменений» Google.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты не ходят в сеть: Google и Claude подменены, фикстуры повторяют реальную структуру вашей таблицы.
