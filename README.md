# legalcareerist — трекер целей «12-недельный год»

Личное веб-приложение для ведения бизнеса «Карьерный юрист» по методу
**12-недельного года**: три бизнес-цели, четыре блока (13.09–31.12.2026),
еженедельные лид-показатели, финансовые факты, автоматический execution
score и сигналы «зелёный / жёлтый / красный / синий» о том, приближают ли
текущие действия к цели.

## Как запустить

Приложение — статичный SPA без сборки и без сервера. Данные хранятся
локально в браузере (`localStorage`), никакого бэкенда не требуется.

```bash
# любой локальный http-сервер, например:
python3 -m http.server 8000
# затем открыть http://localhost:8000/
```

Открыть `index.html` напрямую двойным кликом тоже работает в большинстве
браузеров, но локальный сервер надёжнее (некоторые браузеры ограничивают
`localStorage`/`fetch` для `file://`).

## Структура

- `index.html` — разметка и вкладки.
- `css/styles.css` — минималистичный UI.
- `js/config.js` — заводская конфигурация цикла: 3 цели (G1–G3), 4 блока с
  промежуточными целями, направления деятельности, лид-показатели.
- `js/dates.js` — работа с датами, блоками и неделями внутри блоков.
- `js/storage.js` — персистентность в `localStorage`.
- `js/calc.js` — вся расчётная логика (execution score, прогресс к целям,
  сигналы, линейный прогноз).
- `js/csv.js` — экспорт данных в CSV.
- `js/app.js` — рендеринг вкладок и обработка форм.

## Вкладки

1. **Дашборд** — 3 цели с прогресс-барами (блок/цикл), execution score
   недели по направлениям, сигналы с пояснением, задачи текущей недели,
   блок «на что обратить внимание».
2. **Задачи** — быстрое добавление и список задач (направление, цель,
   неделя, приоритет, тип связи с целью, статус).
3. **Ежедневный отчёт** — задачи на дату со статусами + свободная заметка
   «что сделал».
4. **Лид-показатели** — план/факт по неделе, авторасчёт execution score.
5. **Финансы** — ввод фактической выручки/дохода по направлениям,
   текущий факт по каждой цели.
6. **Блоки / Отчёты** — редактируемые промежуточные цели блоков, отчёт по
   блоку (факт vs цель, средний execution score, невыполненные задачи с
   переносом в следующий блок, рекомендации), прогноз методом линейной
   экстраполяции.
7. **Экспорт / Настройки** — выгрузка задач/лид-показателей/финансов в
   CSV, сброс данных.

## Ключевая логика сигналов

Для каждой цели раз в неделю сравниваются execution score (лид-показатели,
норма — 85%) и факт по деньгам (лаг-показатель, растёт ли по графику
блока):

| Execution score | Деньги растут по графику | Сигнал |
|---|---|---|
| ≥ 85% | да | 🟢 зелёный |
| ≥ 85% | нет | 🟡 жёлтый — действия не конвертируются в результат |
| < 85% | нет | 🔴 красный — отставание и по действиям, и по деньгам |
| < 85% | да | 🔵 синий — результат по инерции/другой источник |

Стек и структура рассчитаны на MVP из ТЗ (`docs/TZ_12_week_year_tracker.md`).
