# legalcareerist — трекер целей «12-недельный год»

Личное веб-приложение для ведения бизнеса «Карьерный юрист» по методу
**12-недельного года**: три бизнес-цели, четыре блока (13.09–31.12.2026),
дневная норма (лид-показатели), финансовые факты, автоматический execution
score, сигналы «зелёный / жёлтый / красный / синий» и OKR по блокам.

## Как запустить

Приложение — статичный SPA без сборки и без сервера. Данные хранятся
локально в браузере (`localStorage`), никакого бэкенда не требуется.

```bash
# любой локальный http-сервер, например:
python3 -m http.server 8000
# затем открыть http://localhost:8000/
```

Открыть `index.html` напрямую двойным кликом тоже работает в большинстве
браузеров, но локальный сервер надёжнее (некоторые браузеры ограничивают
`localStorage`/`fetch` для `file://`).

## Структура

- `index.html` — разметка и вкладки.
- `css/styles.css` — UI (navy-палитра, карточки с тенью).
- `js/config.js` — заводская конфигурация: 3 цели (G1–G3), 4 блока с
  промежуточными целями, направления деятельности, дневная норма,
  автоопределение типа связи задачи с целью.
- `js/dates.js` — работа с датами, блоками и неделями внутри блоков.
- `js/storage.js` — персистентность в `localStorage`.
- `js/calc.js` — расчётная логика (execution score из дневной нормы,
  прогресс к целям, сигналы, линейный прогноз).
- `js/business.js` — механика КЮ Кадры / КЮ Сообщество / КЮ Мероприятия /
  КЮ Маркетинг, дневная норма, ежемесячный отчёт, OKR по блокам.
- `js/app.js` — рендеринг вкладок и обработка форм, отмена действия (undo).

## Вкладки

1. **Дашборд** — 3 цели как стат-плитки (иконка, факт, прогресс блок/цикл),
   execution score недели по направлениям, сигналы с пояснением, задачи
   текущей недели, блок «на что обратить внимание».
2. **Задачи** — быстрое добавление задачи: направление, цель, приоритет.
   Неделя/блок определяются автоматически по плановой дате, тип связи с
   целью — автоматически по названию задачи.
3. **Ежедневный отчёт** — задачи на дату (невыполненные с прошлых дней
   подтягиваются автоматически) + «Дневная норма» — чек-лист того, что
   нужно делать каждый день, по направлениям.
4. **Финансы** — ввод фактической выручки/дохода по направлениям, текущий
   факт по каждой цели.
5. **КЮ Кадры** — годовая воронка найма: помесячный план/факт по 9
   показателям.
6. **КЮ Сообщество** — когорта резидентов, тарифы подписки, дневной P&L
   (эквайринг/налог/резерв/прибыль), итог по месяцам.
7. **КЮ Мероприятия** — каталог билетов и полезных материалов, помесячные
   продажи.
8. **КЮ Маркетинг** — проекты (в работе/готово) и KPI по соцсетям, PR,
   сотрудничеству, рекламе.
9. **Блоки / Отчёты** — редактируемые промежуточные цели блоков, отчёт по
   блоку, прогноз, ежемесячный отчёт только по «Карьерному юристу»
   (без личного дохода и накоплений), OKR блока.

Выручка КЮ Кадры / КЮ Сообщества / КЮ Мероприятий автоматически
синхронизируется в финансовые факты (вкладка «Финансы»): при расхождении
между источниками одной и той же цифры используется бОльшее значение.

**Отмена действия** — кнопка «Отменить» (Ctrl+Z) в шапке, до 30 шагов назад.

## Ключевая логика сигналов

Для каждой цели раз в неделю сравниваются execution score (факт дневной
нормы к плану, норма — 85%) и факт по деньгам (лаг-показатель, растёт ли
по графику блока):

| Execution score | Деньги растут по графику | Сигнал |
|---|---|---|
| ≥ 85% | да | 🟢 зелёный |
| ≥ 85% | нет | 🟡 жёлтый — действия не конвертируются в результат |
| < 85% | нет | 🔴 красный — отставание и по действиям, и по деньгам |
| < 85% | да | 🔵 синий — результат по инерции/другой источник |
