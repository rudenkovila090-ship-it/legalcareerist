# Карьерный юрист

## Мост Instagram ↔ @LegalcareeristBot

Сервис принимает вебхуки Instagram (комментарии и личные сообщения) и:

- на комментарий с ключевым словом отправляет личное сообщение со ссылкой на бота, сайт или оплату;
- ведёт автоответ и квалификацию в Instagram DM (клиент, работодатель, кандидат, сообщество);
- пересылает готовые заявки и сообщения менеджеру в Telegram через @LegalcareeristBot.

**Инструкция по подключению:** [docs/INSTAGRAM_SETUP.md](docs/INSTAGRAM_SETUP.md)

| Что | Где |
|---|---|
| Тексты, ключевые слова, вопросы | `config/flows.json` |
| Переменные окружения | `.env.example` |
| Код | `bridge/` |
| Тесты | `tests/` (`pip install -r requirements-dev.txt && pytest`) |
